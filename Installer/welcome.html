Welcome to cURL to Code __VERSION__

Paste a curl command, get ready-to-run code.

This installer puts cURL to Code in your Applications folder.

  • Converts curl commands, including ones copied from a browser's developer tools (Copy as cURL).
  • Handles headers, cookies, JSON and form bodies, file uploads, login, proxy and timeout options.
  • Opens commands from files, and copies or saves the generated code.

Requires macOS 13 Ventura or later. Runs natively on Apple silicon and Intel Macs.
