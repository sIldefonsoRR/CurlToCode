cURL to Code is installed

Find it in your Applications folder or with Spotlight (⌘ Space, then type “cURL”).

  1. Paste a curl command on the left, or choose File ▸ Open cURL File…
  2. Pick a language from the chips at the top (⌘1–⌘9).
  3. Click Copy or Save… to use the generated code.

Choose Help ▸ cURL to Code Help (⌘?) any time for tips and the list of supported options.

To uninstall, drag cURL to Code from Applications to the Trash.
